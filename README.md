# Graphy - Ultimate FPS Counter - Stats Monitor & Debugger (Unity)

Graphy is an easy to use FPS counter, stats monitor, and debugger for Unity projects.

## Main Features

- Graph and text modules for FPS, memory, and audio.
- Advanced device information.
- Debugging tools.
- Customizable look and feel.
- Multiple layouts.
- Custom inspector.
- Hotkeys.
- Runtime API.
- Multi-platform support.
- Background mode.
- Unity 2019.4 or newer.

## Installation
### Unity Package Manager
```
https://github.com/ThanhDV143/Fork.Lib.Graphy.git
```

1. In Unity, open **Window** -> **Package Manager**.
2. Press the **+** button, choose "**Add package from git URL...**"
3. Enter url above and press **Add**.

### Scoped Registry

1. In Unity, open **Project Settings** -> **Package Manager** -> **Add New Scoped Registry**
- ``Name`` ThanhDVs
- ``URL`` https://upm.thanhdv.com
- ``Scope(s)`` thanhdv

2. In Unity, open **Window** -> **Package Manager**.
- Press the **+** button, choose "**Add package by name...**" -> ``thanhdv.fork.tayx.graphy``
- or
- Press the **Packages** button, choose "**My Registries**"
